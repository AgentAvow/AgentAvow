# Profile pointer

The normative optional verification-result profile is
[ctef-v0.3.4-proof-obligation-results.md](../ctef-v0.3.4-proof-obligation-results.md)
(CC BY 4.0). This file remains as a compatibility pointer for the earlier
PROFILE_SPEC.md path.

The runnable serialization is in VECTORS.json; the machine-readable result
schema is result.schema.json; the zero-dependency evaluator is profile.mjs.
The profile is optional and does not alter base CTEF parsing or require a
particular runtime.
